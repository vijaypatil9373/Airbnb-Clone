# 🌍 Wanderlust – Full Stack Travel Platform

A full-stack travel listing web application where users can explore destinations, create listings, post reviews, and manage their own content.

## ✨ Features

- 🔐 User Authentication & Authorization
- 🏡 Create, Edit & Delete Listings
- ⭐ Ratings and Reviews
- 👤 User-specific Listing Management
- 🗺️ Interactive Maps & Location Support
- 📱 Responsive User Interface
- ✅ Form Validation & Error Handling
- ☁️ Cloud Database Integration

## 🛠️ Tech Stack

**Frontend**
- HTML5

**Backend**

## 🚀 Getting Started

```bash
git clone YOUR_REPOSITORY_URL
cd wanderlust
npm install
npm start
```

Create a `.env` file and add the required environment variables.

```env
MONGO_URI=your_mongodb_connection_string
MAP_TOKEN=your_map_token
SESSION_SECRET=your_secret
```

> Never commit your `.env` file to GitHub.
